# Last Breath (Minecraft 1.20.1, Forge 47.3.0)

Build (JDK 17 + Gradle 8.1.1):

    gradle build

Jar: `build/libs/lastbreath-1.20.1-1.0.1.jar` (put in `mods/` on the server AND on every client).

No Gradle locally? Push this folder to GitHub: the Actions workflow `.github/workflows/build.yml` builds the jar and attaches it as an artifact.
